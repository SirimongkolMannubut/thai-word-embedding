# 🎵 Thai Voice Song & Word Embedding Finder (Next.js)

เว็บแอปพลิเคชันค้นหาเพลงไทยตามอารมณ์/ความรู้สึก และสำรวจคำที่มีความหมายใกล้เคียงด้วย **Word Embedding ภาษาไทย** พร้อมรองรับการ **ค้นหาด้วยเสียงพูด (Voice Search)** พัฒนาด้วย **Next.js 15 + Tailwind CSS** พร้อม Deploy บน **Vercel**

---

## 🌟 ฟังก์ชันเด่น

1. **🎙️ Voice Search (ค้นหาด้วยเสียงภาษาไทย)**
   - กดปุ่มไมโครโฟน พูดอารมณ์หรือคำที่ต้องการ (เช่น *"อยากฟังเพลงอกหัก"*, *"เพลงคลั่งรัก"*, *"ชิลริมทะเล"*)
   - ระบบแปลงเสียงพูดเป็นข้อความภาษาไทย (`th-TH`) และค้นหาให้อัตโนมัติ

2. **🎵 ค้นหาเพลงไทยจากอารมณ์และความหมาย (Semantic Song Finder)**
   - คำนวณความตรงกันระหว่างอารมณ์ของคำค้นหากับเพลงด้วย Word Embedding
   - แสดงชื่อเพลง, ศิลปิน, ท่อนฮุก, ป้ายกำกับอารมณ์, และคะแนนความตรงกัน (%)
   - ลิงก์ตรงไปฟังเพลงบน **YouTube** และ **Spotify** ทันที

3. **🔎 คำใกล้เคียง (Word Embedding Explorer)**
   - แสดง 10 คำที่มีบริบทใกล้เคียงที่สุด พร้อมคะแนน Cosine Similarity (100 มิติ)
   - แถบ Progress Bar สวยงาม และสามารถคลิกเพื่อค้นหาเพลงต่อได้

4. **🔊 Text-to-Speech (TTS)**
   - มีปุ่มให้ระบบอ่านออกเสียงสรุปผลการค้นหาเป็นภาษาไทย

---

## 🚀 การรันบนเครื่อง Localhost

```bash
# 1. ติดตั้งไลบรารี
npm install

# 2. รันโหมด Development
npm run dev
```

เปิดเว็บเบราว์เซอร์ที่: **`http://localhost:3000`**

---

## ☁️ ขั้นตอนการ Deploy บน Vercel

1. Push โฟลเดอร์โปรเจกต์นี้ขึ้น **GitHub Repository**
2. ไปที่ **[vercel.com](https://vercel.com)** ➔ ล็อกอิน ➔ คลิก **"Add New..."** ➔ **"Project"**
3. เลือก Repository ของคุณ แล้วกด **"Deploy"**
4. Vercel จะตรวจจับ Next.js และ Build ให้ทันที
